# Cordial

<!-- description: Roblox's Android client, running natively on Linux. -->

Cordial loads Roblox's official Android x86-64 client directly on Linux, with
no Android emulator or container. It is experimental, and Roblox does not
support third-party clients, so test it with an account you would not mind
losing.

Installing it is covered in the
[README](https://github.com/luohoa97/cordial#install) and in
[Installing Cordial](install.md). These pages cover what you can change once it
runs, and how to build on it.

<!-- cards -->
- [Plugins](plugins-overview.md): Small programs that add features to Cordial, such as Discord status or FastFlag presets.
- [Asset overrides](asset-overrides.md): Replace the app's own textures, fonts and interface images, without modifying any files.
- [Writing a plugin](plugin-development.md): From an empty folder to a working plugin, and the full API reference.
- [Releases](releases/v0.23.2.md): What each version changed, and what is still broken in it.
<!-- /cards -->
