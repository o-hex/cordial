# Cordial 0.21.0: plugins, mouse acceleration

## Plugins

- **Plugins that could not start no longer flood the log.** A plugin that
  failed to start was retried every second for the whole session, three log
  lines each time. Now it is tried once and reported once. It is tried again
  when its files or permissions change, or when whatever it was missing turns
  up. A plugin waiting for Deno starts as soon as Deno is installed, with no
  restart.
- **Installs that had Deno may have been told they did not.** When Cordial ran
  plugins without an OS sandbox, which is always the case in the Flatpak, it
  looked for a `deno` command on the system path instead of the copy Cordial
  had downloaded, and then reported "Deno is not installed". It now runs the
  copy it found. This was worked out from the code and a user's log, and has
  not been confirmed in the Flatpak yet.
- **A plugin update that asks for permissions you never granted now stays
  stopped.** Settings > Plugins shows "Update needs approval" with what it
  wants. It starts once you grant them. Before, it could restart on the old
  permission list.

## Mouse acceleration applies to the camera by default

New profiles now apply your desktop's mouse acceleration to the camera as well
as the cursor. For raw camera movement, choose **Only the cursor** under
Settings > "Use system mouse acceleration settings". A profile that already
saved that setting keeps its choice.

## What is still broken

**The signed-in startup freeze is not fixed.** It still happens on some
launches, in bursts.

**Resizing the window does not redraw the game until you stop dragging.**

**The screen may still grey out when a text box takes focus in fullscreen**
([#53](https://github.com/luohoa97/cordial/issues/53)), and games that put the
cursor in a text box for you may not accept typing.

**A game's `DF` FastFlags, such as `DFIntTaskSchedulerTargetFps`, can reset
partway through a session.**

**Some games show the mobile (touch) interface.**

**The `cordial`, `cordial-bin` and `cordial-git` packages on the AUR are not
published by this project** and are at 0.17.0. Use the release package or the
signed pacman repository instead.
