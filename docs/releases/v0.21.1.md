# Cordial 0.21.1: the packages 0.21.0 was missing

0.21.0's release page had only the Flatpak bundles. A test failed on the
Fedora ARM64 package build, and that stopped every other package from being
attached. This release has the AppImage, `.deb`, `.rpm` and Arch packages
again, and nothing else changed for users.

Everything in [0.21.0](https://github.com/luohoa97/cordial/releases/tag/v0.21.0)
applies: plugins that cannot start are reported once instead of every second,
a plugin update asking for permissions you never granted waits for approval,
and mouse acceleration applies to the camera by default. Its notes also list
what is still broken.
