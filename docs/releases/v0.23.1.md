# Cordial 0.23.1: FastFlags that stay set, and a frame rate limit

## `DF` FastFlags no longer reset while you play

Flags such as `DFIntTaskSchedulerTargetFps` used to work for about two minutes
and then go back to Roblox's value, because the game fetches its settings
again while it runs ([#61](https://github.com/luohoa97/cordial/issues/61)).
Cordial now notices that refresh in the game's own log and applies your
overrides again straight after it. This covers every flag you set, from
`flags.json`, a plugin or Settings. Set `CORDIAL_NO_FLAG_REDELIVERY=1` to turn
it off.

The same idea was sent as a pull request by burlone0
([#73](https://github.com/luohoa97/cordial/pull/73)) and shaped what shipped.

## Frame rate limit

Settings has a **Frame rate limit**: Display refresh (the default), 90, 120,
144, 165 or 240. It applies to a running game. Going back to Display refresh
takes effect at Roblox's next settings refresh, up to two minutes. A limit
above your monitor's refresh rate needs a monitor that fast: on a 60 Hz screen
a higher limit measured worse, not better.

## The text editor appears without working Vulkan

When there is no hardware Vulkan, Cordial now draws its window with GTK's
cairo renderer, so a focused text box shows its editor instead of a blank or
grey game ([#53](https://github.com/luohoa97/cordial/issues/53)). Setting
`GSK_RENDERER` yourself still wins. This is not yet confirmed on the
reporter's machine.

## Contributed fixes

- **No crash entering fullscreen on AMD's RADV driver**, by kaicsm
  ([#72](https://github.com/luohoa97/cordial/pull/72), for
  [#39](https://github.com/luohoa97/cordial/issues/39)).
- **Pointer lock works on KDE Plasma (Wayland)**, so the camera turns with a
  right-drag or shift lock, by burlone0
  ([#70](https://github.com/luohoa97/cordial/pull/70)). Only KDE is affected.
- **Missing textures on GPUs without ETC2 support**, such as studs and some
  materials on NVIDIA under Vulkan, are now decoded by Cordial, by burlone0
  ([#69](https://github.com/luohoa97/cordial/pull/69)). The author found and
  tested it on an RTX 5070; the changes made on top before merging have not
  run on NVIDIA yet. Set `CORDIAL_NO_ETC_EMULATION=1` to turn it off.

## Also

- The doctor now checks NVIDIA-specific things: the driver series, whether the
  Flatpak's NVIDIA extension matches your driver, and kernel modeset.
- The Shaders and MangoHUD install hints now give the right command: the
  Flatpak extension's `//25.08` branch (choosing `stable` installs one that is
  never loaded, [#68](https://github.com/luohoa97/cordial/issues/68)), or your
  distribution's own package command.
- Settings > Plugins: development plugins are listed with installed ones
  (marked "Development"), can be removed from Cordial's list (the folder is
  kept), and turning off "Use plugins" now greys out every plugin control.
- The Flatpak is now the recommended install.

## What is still broken

**The signed-in startup freeze is not fixed.**

**Resizing the window does not redraw the game until you stop dragging.**

**Movement keys sometimes stop working after joining a game**
([#29](https://github.com/luohoa97/cordial/issues/29)); respawning or
re-joining brings them back.

**A Roblox version released only for ARM64 is not shown on x86_64 machines.**

**Some games show the mobile (touch) interface.**

The rest of the list in the
[0.23.0 notes](https://github.com/luohoa97/cordial/releases/tag/v0.23.0) still
applies.
