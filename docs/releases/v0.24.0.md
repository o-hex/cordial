# Cordial 0.24.0: VR, chat boxes that clear, and Roblox without Sober

## Play in VR (experimental)

Cordial can run Roblox's **Meta Quest** build on an x86-64 PC and show it in
your headset through an OpenXR runtime such as WiVRn, SteamVR or Monado. You
copy Roblox off your own Quest in **Settings → VR → Get It from Your Quest**
and start it from **Play in VR** on the same page. Cordial never downloads a
Quest build, and refuses one Roblox did not sign. Use an alt account. See
[Playing in VR](https://cordial.mintlify.app/vr).

This was written and tested by johnnydevelops
([#75](https://github.com/luohoa97/cordial/pull/75)) on a Quest 3 over WiVRn
and on Monado's simulated headset. No frame rate has been measured on a real
headset yet.

## Chat boxes clear after Enter

In a chat box, pressing Enter sent the message but left the text in the box,
and typing more continued on a new line. Enter now sends and the box clears the
way it does on a phone
([#93](https://github.com/luohoa97/cordial/issues/93)). Text Roblox puts into
a box itself (clearing it, or filling it in) now shows up in the editor too.
This was tested on a synthetic box, not yet on a real chat send, so please say
on #93 if a box misbehaves. `CORDIAL_EDITOR_GTK_ENTER=1` restores the old Enter.

## Cordial's own Roblox, not Sober's

If Sober is installed, **Settings → Roblox** now offers **Download Roblox** on
the APK row. Press it and Cordial keeps a verified copy of its own and uses that
from then on, whether or not Sober stays installed. The **Engine directory** row
is gone: nobody needs to choose it.

## Also

- **FPS Flex** gets a frame rate cap (60 to 240), and its settings now take
  effect: a built-in plugin's flags were read from the wrong folder. By
  burlone0 ([#74](https://github.com/luohoa97/cordial/pull/74)).
- **NVIDIA:** a second user's measurements on an RTX 4070, and a failed
  watchdog start is now reported instead of silently ignored. By wiktorekdev
  ([#91](https://github.com/luohoa97/cordial/pull/91)).
- **Documentation** is now a site, [cordial.mintlify.app](https://cordial.mintlify.app),
  built from the same pages as the repository, with shorter guides and a
  plugin developer section.
- The Nix flake builds, and `cordial --diagnostics` says "nix" for a Nix install.

## What is still broken

**The signed-in startup freeze is not fixed**
([#92](https://github.com/luohoa97/cordial/issues/92)).

**Movement keys sometimes stop working after joining a game**
([#29](https://github.com/luohoa97/cordial/issues/29)). Respawning brings them
back. If it happens to you, say whether a controller (or anything that looks
like one) is connected.

**A touchscreen can crash the client**
([#36](https://github.com/luohoa97/cordial/issues/36)).

**Signing in to an account with two-step verification can crash the Flatpak**
([#90](https://github.com/luohoa97/cordial/issues/90)). Use Quick Log In on
Roblox's sign-in screen instead.

**Some games show the mobile (touch) interface.**

The rest of the list in the
[0.23.0 notes](https://github.com/luohoa97/cordial/releases/tag/v0.23.0) still
applies.
