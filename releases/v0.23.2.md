title: "Cordial 0.23.2: the game follows a window resize"
---
## Resizing redraws while you drag

Dragging the window's edge used to leave the game at its old size until you
stopped moving the pointer, then jump. The game now follows the drag, about
ten times a second, and ends at the exact size once you let go.

This was measured in a nested Sway session. It has not yet been checked on
GNOME, KDE or an AMD GPU, so if resizing flickers or crashes for you, please
say so on [#39](https://github.com/luohoa97/cordial/issues/39).
`CORDIAL_RESIZE_MAX_LAG_MS=100000` brings back the old behaviour.

## What is still broken

**The signed-in startup freeze is not fixed.**

**Movement keys sometimes stop working after joining a game**
([#29](https://github.com/luohoa97/cordial/issues/29)). Respawning or
re-joining brings them back.

**A touchscreen can crash the client**
([#36](https://github.com/luohoa97/cordial/issues/36)).

**A Roblox version released only for ARM64 is not shown on x86_64 machines.**

**Some games show the mobile (touch) interface.**

The rest of the list in the
[0.23.0 notes](https://github.com/luohoa97/cordial/releases/tag/v0.23.0) still
applies.
