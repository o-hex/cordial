title: "Cordial 0.29.0: record your game, and the X11 camera stops spinning"
---
## What you can do now

- **Record gameplay to a video file.** Turn on **Settings → Record gameplay**
  (it applies the next time a game starts), or start Cordial with
  `CORDIAL_RECORD=1`. Files go to `Videos/Cordial`, or to the profile's
  `recordings` folder in the Flatpak, as MP4 or WebM depending on what your
  ffmpeg can encode. See [Recording](https://cordial.mintlify.app/recording).
  ([#33](https://github.com/luohoa97/cordial/issues/33))
- **The camera no longer spins or jumps on X11.** Mouse movement that queued up
  while the game was busy was counted several times over, and movement from
  before the pointer locked could turn into a constant 180° spin
  ([#41](https://github.com/luohoa97/cordial/issues/41)).
- **Enter sends chat again.** Pressing Enter in a chat or phone text box
  submitted nothing in some games
  ([#94](https://github.com/luohoa97/cordial/issues/94)).
  `CORDIAL_RETURN_PASSTEXT=0` turns the change off if it causes trouble.
- **Roblox's sign-in security check opens.** When Roblox asks for one, Cordial
  now shows it instead of ignoring the request
  ([#83](https://github.com/luohoa97/cordial/issues/83)).
- **Clearer sound messages.** A PulseAudio-only system no longer logs a false
  PipeWire error, Cordial says plainly when no sound server answered, and a
  PipeWire that starts late is tried again
  ([#104](https://github.com/luohoa97/cordial/issues/104)).
- **A launcher that never shows its window now says why.** After 20 seconds it
  prints the last step it reached
  ([#38](https://github.com/luohoa97/cordial/issues/38)).
- **Log channel overrides warn when they would go silent.** A number silences
  some of Roblox's log channels; Cordial now warns at launch and
  [FastFlags](https://cordial.mintlify.app/fastflags) says to use a severity
  name such as `Verbose` ([#13](https://github.com/luohoa97/cordial/issues/13)).
- **Report a Problem's log zip shows more:** which font each text box is drawn
  in, and any second-long stall in the loop that delivers input.

## What is still broken

**Recording has only been tried signed out**, for under a minute at a time.
Sound is everything your default output plays, not the game alone, and there
is no hotkey.

**The Enter and security-check fixes are untested in a real game or a real
sign-in.** Please report on the issues above either way.

**The signed-in startup freeze.** Roblox can stop drawing on the loading screen
after sign-in. The launcher restarts a client stuck that way, up to twice.

**Movement keys can be dead after joining a game.** Move the mouse while the
place loads and it does not happen
([#29](https://github.com/luohoa97/cordial/issues/29)).

**An occasional crash right after start** on compositors without GPU buffer
sharing, such as sway's software renderer. The cause is understood and not yet
fixed ([#63](https://github.com/luohoa97/cordial/issues/63)).

**Hyprland: the cursor moves while you drag the camera**, as in 0.28.0.

The rest of the list in the
[0.28.0 notes](https://github.com/luohoa97/cordial/releases/tag/v0.28.0) still
applies.
