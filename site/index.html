Cordial

Play Roblox on Linux.

Install Flatpak · x86-64 · needs a Vulkan GPU

Cordial runs Roblox’s official Android build natively on your machine — no Wine, no emulator, no Android container. It fetches the build from Roblox itself the first time you launch it.

What you get

Profiles

Separate sign-ins, settings and caches. Each one is locked to a single running instance, so two windows can’t corrupt each other’s data.

Plugins

Discord presence, custom textures and sounds, and more. A plugin never gets a socket or a file — it asks, and Cordial does it.

Settings that tell you what happened

Every Roblox flag you set, and every conflict between them, printed at startup. No config file with a “don’t edit this by hand” warning at the top.

Status

Honest about the gaps, because finding out after installing is worse.

✅Signing in, staying signed in, browsing and launching experiences
✅Graphics, audio, mouse look and keyboard
✅Web views — servers, profiles, marketplace
✅Asset caching between sessions
⚠️Text entry is incomplete in some in-experience fields
❌Passkey sign-in. If your account uses a passkey for two-factor, you can’t sign in yet — WebKitGTK has no WebAuthn support and that isn’t something Cordial can work around
❌Voice chat

Install

flatpak remote-add --if-not-exists --no-gpg-verify \
    cordial https://luohoa97.github.io/cordial/repo

flatpak install cordial io.github.luohoa97.Cordial

Then launch it, sign in, and press play. Nothing from Roblox is bundled or redistributed — Cordial downloads the official build to your machine and never re-serves it.
